# Design System pour le site web sur la convivialité urbaine

## Palette de couleurs

### Couleurs principales
- **Vert convivial** : `#2A9D8F` - Représente la durabilité, la nature en ville, la fraîcheur
- **Bleu urbain** : `#264653` - Représente le cadre urbain, la stabilité, la sérénité
- **Ocre chaleureux** : `#E9C46A` - Représente la chaleur humaine, la convivialité, l'accueil

### Couleurs secondaires
- **Terracotta** : `#F4A261` - Pour les accents et les appels à l'action
- **Rouge brique** : `#E76F51` - Pour les éléments importants et les alertes
- **Vert clair** : `#8BD8BD` - Pour les éléments secondaires et les succès

### Couleurs neutres
- **Blanc cassé** : `#F8F9FA` - Fond principal
- **Gris clair** : `#E9ECEF` - Fond secondaire, cartes
- **Gris moyen** : `#ADB5BD` - Texte secondaire, bordures
- **Gris foncé** : `#495057` - Texte principal
- **Noir doux** : `#212529` - Titres, texte important

## Typographie

### Titres
- **Police** : "Montserrat", sans-serif
- **Poids** : 700 (Bold) pour les titres principaux, 600 (Semi-Bold) pour les sous-titres
- **Tailles** :
  - H1 : 2.5rem (40px)
  - H2 : 2rem (32px)
  - H3 : 1.75rem (28px)
  - H4 : 1.5rem (24px)
  - H5 : 1.25rem (20px)
  - H6 : 1rem (16px)

### Corps de texte
- **Police** : "Open Sans", sans-serif
- **Poids** : 400 (Regular) pour le texte normal, 700 (Bold) pour l'emphase
- **Taille** : 1rem (16px) pour le texte principal, 0.875rem (14px) pour le texte secondaire

### Citations
- **Police** : "Playfair Display", serif
- **Style** : Italic
- **Poids** : 400 (Regular)
- **Taille** : 1.25rem (20px)

## Espacement

- **Unité de base** : 0.25rem (4px)
- **Espacement entre paragraphes** : 1.5rem (24px)
- **Espacement entre sections** : 4rem (64px)
- **Marge intérieure des conteneurs** : 1.5rem (24px)

## Composants UI

### Boutons
- **Primaire** : Fond `#2A9D8F`, texte blanc, arrondi 0.25rem
- **Secondaire** : Fond transparent, bordure `#2A9D8F`, texte `#2A9D8F`, arrondi 0.25rem
- **Tertiaire** : Fond transparent, texte `#2A9D8F`, pas de bordure
- **État hover** : Assombrir légèrement la couleur de fond, transition douce

### Cartes
- **Fond** : Blanc
- **Ombre** : Légère, 0 4px 6px rgba(0, 0, 0, 0.1)
- **Arrondi** : 0.5rem (8px)
- **Bordure** : Aucune ou très légère (1px) en `#E9ECEF`

### Navigation
- **Menu principal** : Fond `#264653`, texte blanc
- **Menu secondaire** : Fond blanc, texte `#264653`
- **Indicateur actif** : Barre inférieure ou accent `#E9C46A`

## Iconographie
- Style épuré et cohérent
- Taille uniforme
- Couleurs adaptées au contexte (primaire, secondaire)
- Utilisation des icônes Lucide préinstallées

## Animations et transitions
- Transitions douces (0.2s - 0.3s)
- Animations subtiles pour les interactions
- Effets de parallaxe légers pour certaines sections
- Apparition progressive des éléments au scroll

## Responsive Design
- **Mobile first** : Design optimisé d'abord pour mobile
- **Breakpoints** :
  - Mobile : < 640px
  - Tablette : 640px - 1024px
  - Desktop : > 1024px
- Adaptation des tailles de police et espacements selon les breakpoints
- Réorganisation des layouts pour une expérience optimale sur chaque appareil
